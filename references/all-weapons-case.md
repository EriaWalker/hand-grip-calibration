# RifleGirl 全武器校准：新增经验与验证范围

记录日期：2026-09-14。Unity 6000.3.21f1，roach 项目的 `Assets/Demo/Level/DemoLevel.unity`，角色 `Rifle_Full_Body`，可见身体蒙皮 `Body_Sportswea`。框架行为来自该项目当时安装的源码，不能仅凭 Unity 版本推断其他项目的插件行为。

本页是历史运行结果与可复用经验，不包含插件源码、角色/武器网格或可直接安装的握姿资产。本次文档发布没有重新执行 Unity 校准。

## 案例范围

| 武器 | 左手案例 | 右手案例 | 非握把配件选项 |
| --- | --- | --- | ---: |
| Knife | 无，左手 IK 禁用 | 1 | 0 |
| Mk18 | 无握把、垂直、斜握把 | 1 | 6 |
| AK12 | 斜握把、无握把、垂直 | 1 | 5 |
| Mk23 | 双手持枪、垂直握把 | 1 | 3 |
| FAL | 固定护木支撑 | 1 | 1 |

合计 8 个可切换握把选项，加 FAL 固定支撑构成 9 个左手案例，再加 5 个右手案例，共 14 个。`Left0` 是各武器自己的索引，并非统一握把类型。15 个非握把配件选项没有手部层覆盖，检查切换后引用保持一致；没有穷举所有配件组合。

保留此前 AK12 斜握把姿势，新增 8 个左手 Legacy 一帧姿势和 5 个原生右手 Pose Offset 设置。左手校正接入实际附件层，并同步对应 Profile 默认层；右手层置于最终 IK 之前。原机器人资产与框架求解器保持原用途。

## 新经验如何改变操作

| 发现 | 后续操作 |
| --- | --- |
| `LinkAnimatorLayer` 按精确设置类型遍历替换所有匹配层 | 添加第二个 Attach Hand 前核对覆盖范围；本案例用不同类型的原生 Pose Offset 负责右手 |
| FAL 的 Pose Sampler 带 X 轴 90° 武器偏移 | 将完整武器变换计入参考快照；约 26 cm 的假位移消除后，拟合修正约为 14–16 mm |
| 部分武器骨架存在 100 倍缩放 | 用显式 LBS、真实部件尺寸与运行烘焙交叉检查，避免重复应用缩放 |
| 参考机器人姿势本身也可能穿透武器 | 参考只提供握持结构；最终用目标蒙皮和分部件武器实体检查 |
| 两手各自不穿武器仍可能互相穿透 | 检查同帧双手三角形；优化后刷新对手实体，不能沿用旧代理 |
| 静止握姿正确仍可能锁住换弹动作 | 检查全层动作曲线权重在释放阶段变为 0、结束恢复为 1 |
| 单手匕首没有左手 Attach Hand，仍可能受左手 IK 影响 | 明确关闭左手 IK；攻击时保持右手修正，左臂保留原生动画 |
| 离线结果与 Humanoid 最终输出可能不同 | 重新装备、等待帧推进，重新导出实际蒙皮验收 |

操作细节见 [层分工与动作权重](unity-workflow.md#左右手层分工与动作权重)、[坐标与缩放](calculation.md#快照坐标与缩放) 和 [双手联合检查](calculation.md#双手联合检查)。这些说明是对现有流程的补充，不是自动批量校准接口。

## 历史验证结果

- **武器接触采样：14/14 通过。** 每手 658 个顶点和 1027 个三角形中心，共 1685 个样本；合计 23,590 个样本。所用武器凸实体内部样本数为零，要求的最小平面间隙为 0.5 mm，实际最低为 0.533689 mm。
- **Mk23 双手：二次修正后通过所用表面检查。** 同帧两手各 1027 个三角形，未发现长度大于 0.1 mm 报告阈值的交线；最近连续表面距离约 0.049066 mm。开放手腕边界、共面接触与数值容差仍限制结论。
- **原生动作流程：** 4 把枪检查瞄准、换弹进行中和结束；换弹时左右手校正权重为 0，结束为 1。Knife 检查攻击进行中和结束，右手校正保持有效，左手 IK 为 0。
- **配件与静态绑定：** 15 个非握把选项切换后保持手部引用；骨骼名称/索引、右手层顺序、动作曲线、单手权重、9 个 Legacy 姿势及默认层同步检查通过。

平面采样间隙不是到复杂武器表面的精确欧氏距离。Mk23 两手的 0.049066 mm 表面距离，也不是其左手到武器约 1.002 mm 的平面采样间隙。两者不可互换，更不能把有限采样通过写成所有三角形无相交。

动作通过原生方法触发，不等同于真实键鼠输入。未执行 Player Build，未覆盖其他服装蒙皮、全部动画帧或所有附件组合。历史 Console 保留了已有错误与早期探针异常；不宣称 Console 零错误。任务结束已退出自行启动的 Play Mode 并恢复后台运行设置。

## 证据出处与复用

原项目报告位于 `Documentation/RifleGirl-All-Weapons-Grip-Calibration.md`，证据目录为 `Documentation/RifleGirl-Grip-Evidence/`。这些是源项目相对路径，**不在本公开仓库中**。

原项目保存了 `static-final-audit.json`、`runtime-check-summary.json`、`mk23-two-hands-final.json`、动作/附件 JSONL、Console 记录、截图和资源修改前后 SHA-256。压缩的运行接触输入可用原项目证据目录中的 `verify.py` 重放；重放验证存档，不证明当前 Unity 场景状态。

本仓库的 `scripts/calibrate.py self-test` 和 `examples/` 仍仅验证合成输入与计算逻辑，不复现上述 14 个 Unity 案例。README 原有“12 个绑定点位、约 90 分钟”是另一条用户提供的测试记录，不是本次案例计数或耗时。
